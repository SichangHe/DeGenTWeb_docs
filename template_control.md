# Body-swap template control

The meeting proposed: “we can just do body swapping like we take existing like negative samples and we swap their bodies for LLM-generated text” (Zoom transcript, 00:20:48–00:21:07, 2026-08-25).

The implementation uses explicit Wix→human and B12→human site pairs already recorded in the baseline manifest. It validates each pair against the repository's trusted AI-site mapping and records that mapping source's digest. It strictly validates the binary labels against ground truth and admits only baseline pages with at least 200 tokens. It deterministically samples three pages from each site, captures the current originals, and creates reciprocal human-shell/generated-content and generated-shell/human-content body swaps. It changes only one selected main-content subtree, verifies the rest of the parsed shell by hash, and records selection decisions, raw labels, ground truth, builder evidence, source URLs, timestamps, selectors, and input/output hashes. It does not create or modify provider sites.

The clean bounded run contains 24 artifacts: two builders, two paired sites, two current-original conditions, two reciprocal body-swap conditions, and three pages per condition. Every extraction passed the 200-token minimum, and all 24 were scored fresh through one client-configured Binoculars connection whose socket identity remained stable. The daemon does not expose an immutable runtime model/config identifier, so this is not proof of backend identity. The finalized run is permission-sealed read-only and an external manifest records the internal inventory's root digest; this detects later changes but is not a cryptographic signature. The detector classified all 24 according to the recorded donor label at the established page threshold. No matched current-original/body-swap pair crossed that threshold. Descriptive median swapped-minus-original score differences ranged from -0.023 to 0.000.

This is a page-level end-to-end extraction-plus-detector implementation control, not a site-level performance estimate. It does not identify template invariance or shell causality: identical normalized extraction establishes identical detector input, while non-identical extraction can reflect shell-text contamination or drift between the frozen donor and current original. Three pages per condition cannot support the nine-decile site SVM or uncertainty claims. A causal template test needs a design that holds detector input fixed or separately measures and models shell text, plus enough independently sampled provenance-safe site pairs and pages for site-level inference.
