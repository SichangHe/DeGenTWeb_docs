Scope and limitations
This directly validates the score's cost and memory on the required hardware.
It does not validate accuracy. The benchmark intentionally uses DW1's dynamic
Falcon checkpoints so the candidate and comparator share hardware, models,
token IDs, documents, batch, sequence length, and timing boundary. The paper's
accuracy was obtained with full-precision Llama-2 or Falcon pairs and cannot be
transferred to these dynamic checkpoints. The released LAPD statistic draws
independent token alternatives from already-computed categorical distributions;
it neither decodes auxiliary text nor performs another model forward. When the
sampling model equals the base model, the official cache-building path reuses its
logits, while the separate multi-GPU runner redundantly forwards the same model.
This harness follows the cache-path behavior, so it is a transparent adapter and
not an unchanged timing of the released multi-GPU command. LAPD uses 10,000
auxiliary categorical samples and is excluded from the qualifying shortlist under
the strict no-multi-perturbation constraint; this cost record is retained only as
research evidence.
