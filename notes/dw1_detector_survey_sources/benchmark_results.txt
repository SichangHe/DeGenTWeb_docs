Scope and limitations
The run directly measures scoring latency and allocated CUDA memory for one warm-up
followed by three timed repetitions under the uniform boundary stated above. It
does not measure accuracy, threshold calibration, sustained throughput,
model-loading time, tokenization, input transfer, or multi-worker contention.
The candidate runs use the DW1 performer model as proxy, not the candidates' paper
default proxy. Their score formulas are faithful, but their effectiveness with this
proxy is unvalidated.

Reproducibility incident
The first run called Binoculars.compute_score directly and failed because, under
Transformers 4.57.3, BatchEncoding.to() mutated the shared encoding before the
two concurrent forwards, leaving the observer's inputs on GPU 1 while its model was
on GPU 0. The successful run uses shallow copies before moving the two encodings,
matching the established path in src/degentweb/classifying/fdgpt_trial.py. No DW1
implementation or configuration was changed.
