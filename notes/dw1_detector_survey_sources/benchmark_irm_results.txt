Scope and limitations
The Qwen2-0.5B family is an evaluated IRM pair in the paper, but not the
paper's highest-scoring Llama-3.2-1B family. The exact Llama artifacts require
authenticated license acceptance, which the approved public-only screen did not
bypass. The local AUROC is a bounded convenience-corpus screen, not calibrated
accuracy: it is not stratified, stored comparators may have different historical
software and truncation bases, and it supplies no low-false-positive threshold.
The timing comparison uses the same hardware, length, and batch, but a separately
recorded Binoculars run rather than a same-process comparator. The official score
direction is instruction-model sequence log-likelihood minus base-model sequence
log-likelihood. The official command binds the instruction checkpoint to a
misleading variable named `base_model`; the harness follows the checkpoint role,
not that variable name. Orientation-free AUROC is also reported because stored
comparators use different score directions.
